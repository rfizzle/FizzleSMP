Inventory sorting gets a full replacement this release, plus keybind combos and cleaner update behavior.

## Added
- Amecs — enables multi-key keybind combos (modifier + key chords) for players who need more bindable actions than vanilla allows
- Inventory Profiles Next — replaces Inventory Essentials as the sorting/management mod. Configured with alphabetical sort as the default, slimmed in-GUI controls, and a rules override that neutralizes the creative-menu sort rule (which froze clients on first use)

## Changed
- Updating the pack no longer overwrites player-customized Minecraft settings (video, controls, etc.)
- guy's Armor HUD — default config now anchors the widget to the bottom-left in vertical orientation instead of the horizontal hotbar-side default

## Removed
- Inventory Essentials — swapped out in favor of Inventory Profiles Next
