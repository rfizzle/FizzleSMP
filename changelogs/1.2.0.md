Ledger is replaced by GriefLogger, light overlays arrive, and several mod integration bugs are fixed.

## Added
- Lighty — light overlay mod with carpet-style, number, and cross visualization modes (F7/F8 toggle)
- Euphoria Patches — add-on for Complementary Shaders with extra visual features and settings
- GriefLogger — SQLite/MySQL-backed player interaction logger, replacing Ledger
- Infinite Trading — prevents villager and wandering trader trades from locking up

## Fixed
- Server crash caused by Ledger's mixin NPE when players interacted with Easy Mob Farm containers — resolved by replacing Ledger with GriefLogger
- NeoEnchant+ Auto Smelt enchantment producing ingots with extra data components that don't stack — disabled via datapack override; Artifacts' Smelting item covers the use case
- CurseForge export rejecting Artifacts and Mod Menu as overrides — reinstalled both from CurseForge source
- YIGD Soulbound enchantment unable to be applied to Traveler's Backpack, Artifacts, and Jewelry items — extended soulbindable item tag via datapack to include modded items

## Removed
- Ledger — abandoned on 1.21.1, crashes with Easy Mob Farm's custom containers
